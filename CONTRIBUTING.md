# Contributing

Thanks for your interest in improving this project!

## How to contribute

1. Fork the repository
2. Create a new branch for your change:

git checkout -b feature/my-feature

3. Make your changes
4. Test them locally (run `python tts_chat.py`)
5. Commit and push:

git commit -m "Add my feature"
git push origin feature/my-feature

6. Open a Pull Request

## What we welcome

- Bug fixes
- New filters or improvements to existing ones
- New voice options
- Translations (README, UI)
- Documentation improvements

## What to avoid

- Committing `tts_config.json` or any file with a real OAuth token
- Large refactors without prior discussion — open an Issue first
- Adding heavy dependencies without a good reason

## Reporting bugs

Open an Issue and include:

- Your OS and Python version
- Steps to reproduce
- The exact error message (copy from the terminal)
- What you expected to happen

## Code style

Keep it simple. No strict style guide — just make sure the code runs and is readable.
